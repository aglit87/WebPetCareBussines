## Why

Архитектурная база приложения разошлась с декларированным FSD: `shared` уже зависит вверх от `entities` и `app`, мок-бэкенд встроен в приложение без единого seam'а для реального API, а ключевые паттерны (состояния загрузки/ошибки, персист) продублированы по всем виджетам. Cейчас моки работают, но подключение реального бэкенда или вынос слоёв в пакет неизбежно упрётся в эти точки. При этом в проекте нет ни одного теста при обилии чистой логики (reauth, автомат auth, даты расписания), от которой зависят деньги пользователей.

## What Changes

- **BREAKING**: `baseQueryWithReauth` перестаёт импортировать `entities/auth` и `app/store` — токены, действия refresh/логаута и тип состояния инжектятся колбэками. Реал-логика становится переиспользуемой и не зависит от домена.
- **BREAKING**: мок-бэкенд выносится из `shared/api/mock` в peer-слой (например `src/mocks/`), который может зависеть от entities; zod-контракты становятся общим источником правды для клиента и мок-хэндлеров.
- Включение моков становится окруженным флагом (`import.meta.env.MODE` / query-параметр), а не безусловным вызовом в `main.tsx` — появляется seam для продакшен-бэкенда.
- Общие компоненты `WidgetError` / `WidgetSkeleton` в `shared/ui` заменяют 10 дублированных экранов ошибки/скелетона в виджетах.
- При `logout`/истечении сессии сбрасывается кэш всех RTK Query API (`api.util.resetApiState`) — исключается утечка данных между пользователями в одном браузере.
- Устраняется дублирование констант и типов: один источник слотов расписания, единый `OtpPurpose`, subtitle дашборда из DTO вместо хардкода.
- Персист в localStorage выносится из редукторов в единую обёртку с заделом на миграции версий.
- Добавляются Vitest, ESLint и CI; unit-тесты покрывают чистую логику: reauth-гонку параллельных 401, автомат состояний auth, `entities/schedule/model/date.ts`, zod-схемы, `getErrorMessage`, мок-хэндлеры.

## Capabilities

Поведение системы для пользователя не меняется — это внутренний рефакторинг (слои, инструменты, дубли). Спеков с требованиями в репозитории нет, а выдумывать требования ради строчки в спеке не будем. В `.openspec.yaml` изменения выставлено `skip_specs: true`.

## Impact

- `src/shared/api/baseQueryWithReauth.ts` — сигнатура и способ конфигурации (инъекция вместо импортов).
- `src/app/store/index.ts`, `src/entities/*/api/*Api.ts` — подключение нового baseQuery и сброс кэша.
- `src/app/providers/enableMocking.ts`, `src/main.tsx` — флаг включения моков.
- `src/shared/api/mock/*` — переезд в новый слой, подключение zod-валидации в хэндлерах.
- `src/widgets/*/ui/*Widget.tsx` — замена дублированных состояний общими компонентами.
- `src/entities/auth/model/slice.ts`, `src/entities/business/model/slice.ts` — вынос персиста.
- `package.json` — новые devDependencies (vitest, eslint, хаски) и скрипты.
- Никаких изменений публичного API для внешних систем — контракты `/api/*` сохраняются в текущем виде.
